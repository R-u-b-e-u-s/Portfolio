Experience

JUNE 2026 – AUGUST 2026

Cyber Operations Intern — Shaw Industries

Worked directly in an enterprise cybersecurity environment focused on detection engineering, threat research, and security architecture. I researched adversary techniques and mapped behaviors to the MITRE ATT&CK framework, then translated those behaviors into Microsoft Sentinel detections using KQL. My detection work covered identity attacks, risky authentication, MFA abuse, privilege escalation, suspicious PowerShell execution, malicious inbox-rule activity, and account-takeover scenarios. I also developed monitoring logic to identify server heartbeat failures and log-ingestion gaps, collaborated with senior cybersecurity engineers to refine alert thresholds and reduce false positives, and created technical documentation and presentations for security and architecture review. In addition, I designed a dedicated Kali Linux purple-team sandbox intended to give security teams a controlled, isolated, and auditable environment for detection validation and authorized testing.
